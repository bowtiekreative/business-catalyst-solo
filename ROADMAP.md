The starter provides native views, source scanning, reviewed file edits, local
commits and undo. The production brief remains the full product specification.

- [ ] Complete milestone 1: native folder picker, cloning, rendered preview,
      richer route/section detection, native accessibility validation.
- [ ] Implement pure typed change operations and real source adapters. Test route
      propagation, navigation, redirects, sitemap and integration environment keys.
- [ ] Add structured content drafts, visual section editing, review diffs,
      restore and a reviewed automatic-push policy.
- [ ] Add provider helpers that return validated proposals, task scope checks,
      usage metering and budget controls. Keep credentials outside source and Git.
- [ ] Add tasks, roadmap acceptance checks and host integration configuration.
- [ ] Add deployment preflight in the brief's prescribed order, real releases,
      live rollback, CLI write commands and the typed MCP surface.
- [ ] Run the complete sample Astro acceptance flow on Windows and Ubuntu;
      publish signed installers and finish release/security/accessibility review.
