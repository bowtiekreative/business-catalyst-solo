# Inter font files

Unmodified static Inter 4.1 TrueType fonts from the official
[Inter release](https://github.com/rsms/inter/releases/tag/v4.1), downloaded
2026-10-19 from `https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip`.
Upstream archive entries: `extras/ttf/Inter-Regular.ttf`,
`extras/ttf/Inter-SemiBold.ttf`, and `LICENSE.txt` (stored here as `OFL.txt`).

- `Inter-Regular.ttf`: weight 400, SHA-256 `40d692fce188e4471e2b3cba937be967878f631ad3ebbbdcd587687c7ebe0c82`.
- `Inter-SemiBold.ttf`: weight 600, SHA-256 `78a843fade9d4612a5567302fb595b56976eb5fcebf4fea5a5912d638bafcde3`.
- `OFL.txt`: upstream SIL Open Font License 1.1 text, SHA-256 `262481e844521b326f5ecd053e59b98c8b2da78c8ee1bdbb6e8174305e54935a`.

Both fonts are embedded in the executable; no runtime font download occurs.
